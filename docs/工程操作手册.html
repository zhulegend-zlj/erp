一、工程负责什么

工程负责工程不管
成品：新建、图片价格：由采购填写
零件：SKU/名称/规格/单位/图片/图档/模具/MOQ供应商：由采购在零件上挂
BOM：成品由哪些零件组成、每件用量采购单/库存/出货/财务

二、操作步骤

1. 录成品（基础资料 → 成品）

点「新建成品」，填写：

字段说明
SKU成品编号，唯一不可重复（如 CSS-SQ、P1927-DAPM）
名称成品名称
单位默认「件」
图片点上传，选成品照片（可选）

2. 录零件（基础资料 → 零件）

点「新建零件」，填写：

字段说明
SKU零件固有编号，照采购单抄（如 P1927-14872），唯一不可重复
名称零件名称（如 变速杆罩）
单位默认「个」（pcs）
规格材质/表面处理等（如 ADC12 电泳黑色）
图片地址点「上传图片」选零件照片
图档地址点「上传图档」传图纸/技术文件：支持 pdf / dwg / dxf / step / stp / igs / zip / xlsx 及图片，单个 ≤ 20MB
模具模具编号（可选）
MOQ最小起订量（可选，整数）
价格不用填（采购负责）
供应商不用填（采购负责挂）
列表会自动按「产品族前缀 + 编号大小」排序（如 CSS-001、CSS-012…，P1927-14872、P1927-14873…），同一产品的零件会排在一起。

3. 配 BOM（基础资料 → BOM 维护）

  1. 顶部「选择成品」下拉里选成品
  2. 点「添加零件」——输入行出现在第一行：下拉选零件、填用量
  3. 继续点「添加零件」可以连续加（新行始终在最上面），最左列有零件图片缩略图
  4. 全部加完点「保存 BOM」

三、上传文件的存放规则（自动的，不用手动整理）

上传图片/图档后，系统自动按下面规则放文件，无需工程手工建目录：

  • 挂在 1 个成品下的零件：成品SKU/零件SKU-零件名/图片.png、图档.pdf
  • 还没配 BOM 的新零件：先放 _未分类/零件SKU-零件名/，保存 BOM 后自动归位到成品目录
  • 一个零件被多个成品共用：放 _共用/

改名零件会同步改文件夹名；删除零件会删掉它的文件。

四、如果手里有现成表格（重要）

不需要一条条手录：把 Excel 表格全部发给开发人员，由开发人员批量导入。建议表格按下面三张 sheet 整理（列名照抄）：

sheet「成品」成品SKU ｜ 成品名称 ｜ 单位
sheet「零件」零件SKU ｜ 零件名称 ｜ 单位 ｜ 规格 ｜ 供应商名称 ｜ 模具 ｜ MOQ
sheet「BOM」成品SKU ｜ 零件SKU ｜ 用量

图片/图档如果也很多：打包发开发人员，文件名按 零件SKU-零件名-图片.png、零件SKU-零件名-图档.pdf 命名，开发人员批量导入后系统会自动放进对应目录。

五、常见问题

  • 遇到问题：右下角「意见反馈」提交，开发人员会看到。
  • SKU 重复会报错「已存在」：说明这条录过了，直接改原记录即可。
  • 忘密码：找开发人员重置。
  • 图片传错：编辑该零件重新上传即可覆盖。
