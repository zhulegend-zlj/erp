## 一、资料前提（销售自己可维护大部分）

## 二、日常流程

### 1. 建订单（订单 → 新建订单）
- 选客户 → **客户PO号（必填，照客户 PO 抄）** → 订单日期（默认今天）→ **客户交期（客户要求到货日，必填）** → **ZRH交货日期（承诺给客户的交货日期 = 车间完成生产目标，必填）** → 付款条件（自动带客户默认，如 NET 60）
- 明细：成品 + 数量 + 单价（可多行）；SKU 即客户料号（CSP_V3 / CSP_V3I / CSS_SQ）
- 建完是「草稿」；点「推进至已确认」后采购才会收到提醒开始备料

### 2. 跟单（看状态）
已确认 → 采购中 → 生产中 → 待出货 → 已出货（销售）→ 已完成（销售）
- **部分出货**：订单出过一批后，列表「已出」列显示 60/100 这样的进度，出满自动变已出货

### 3. 出货排程（出货排程页，按客户每周 OPO 表录）
- 每行：选订单 → 成品 → 数量（不超订单剩余）→ **到货仓**（下拉选，可手填新仓并询问保存）→ **客户要求日 + 承诺日(PD)**（回复客户的日期）
- 仓库看到「待备货」的排程后按仓备货码放（如 V3 100 台 + V3I 50 台 → MEL. 堆放一起），点「已备好」
- 销售可编辑/取消/删除未出货的排程

### 4. 出货（出货页「① 从排程出货」）
- 选到货仓 → 自动列出该仓「已备好」的排程 → 每行填**本次出货数量**（可只出一部分；**同一仓可跨多张订单拼一票**，每行带自己的 PO 号）
- 填单证信息：发票号（手工）、付款条件/贸易条款/唛头（自动带客户默认）、船名航次/ETD/ETA、送货单号、签收人等
- 点「出货」→ 生成出货单+扣库存；排程剩余自动扣减；订单出满自动「已出货」
- 没有排程的单子可用「② 无排程直接出货」（选订单直接出，支持部分/拆行）

### 5. 出货后补录与导出（出货单列表）
- 「编辑单证」：补发票号/柜号/HBL/箱数毛净重等；「添加节点」：备货/装柜/开船/到港/清关
- 「导出单证」：收款发票 Official Invoice（自动带付款记录与英文大写）/ 商业发票 / 装箱单

### 6. 收尾
- 全部出完收款后，订单页「已出货」→「已完成」
- 删除订单：仅无任何业务痕迹可删（需输入订单号确认）

## 三、常见问题
1. 发票抬头空 → 基础资料 → 公司资料 填一次（销售自己就能填）
2. 出货时提示「尚未备好」→ 让仓库在 出货排程 点「已备好」
3. 提示「数量超过订单剩余」→ 检查该成品 已出+排程 是否超订单数量
4. 排程想分两批出 → 第一次只填部分数量出货，排程剩余会保留，下批再出
