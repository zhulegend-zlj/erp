# 销售账号操作手册（ERP 订单 / 出货 / 单证）

> 适用角色：**销售**。负责：销售订单、出货、三份单证导出。
> 系统地址（局域网）：**http://192.168.1.114:5173**
> 登录账号：**销售**　初始密码：**88888888**（开发阶段统一密码，暂不需要修改）

## 一、开工前：请同事先把这些资料备齐（销售自己录不了）

| 资料 | 谁维护 | 位置 | 用途 |
|---|---|---|---|
| 客户（名称/国家/联系人 + **收货地址 / VAT# / EORI / 通知方**） | 采购 或 老板 | 基础资料 → 客户 | 下单选客户；发票/装箱单的 Consignee 自动带出 |
| 成品（SKU/名称 + **英文品名 / 海关编码**） | 工程 或 老板 | 基础资料 → 成品 | 发票 Description 列、报关编码 |
| **公司抬头 / 银行 / SWIFT / VAT / 税率** | 老板 | 基础资料 → 公司资料 | 三份单证的 Issuer/Shipper 与收款银行（空白时导出会缺抬头） |
| 客户收款 | 财务 | 财务页登记并关联订单 | 收款发票「Payment record」自动带入 |

## 二、销售负责什么 / 不负责什么

| 销售负责 | 销售不管（系统里看不到/做不了） |
|---|---|
| 新建订单、确认/回退、删除干净订单、订单完成 | 建/改 客户（采购/老板）、成品（工程/老板）、公司资料（老板） |
| 出货、出货后编辑单证、运输节点、三份单证导出 | 采购单、收货/领料/入库、退补货、收付款登记 |
| 销售单价（仅销售/老板可见） | 零件采购价（对销售隐藏） |

## 三、日常流程（按顺序）

### 1. 建订单（订单 → 新建订单）

- 选客户 → 交货日期 → 明细：成品 + 数量 + 单价（可加多行）
- 同一订单同一成品只能一行；数量为整数，单价为非负数
- 创建后状态 = **草稿**

### 2. 确认订单

- 点「推进至已确认」→ 采购/仓库开始运作
- 确认前可「回退至草稿」；**确认后销售不能再改再退**，只有老板可强制回退

### 3. 跟单（看状态，不用操作）

订单状态自动流转：

> 已确认 → **采购中**（采购生成采购单）→ **生产中**（仓库成品入库）→ **待出货**（采购收齐 + 生产收满，自动变）→ **已出货**（销售出货）→ **已完成**（销售收尾）

订单页 / 看板 都能看阶段标签，日常盯「待出货」。

### 4. 出货（出货页「订单出货（单证中心）」）

1. 下拉选「**待出货**」订单 → 明细行自动带出（数量/单价来自订单，可改）
2. 填整单单证信息：
   - **发票号**（手工，照客人要求，如 ZRH20260814006）
   - 付款条件（如 NET 60）、贸易条款（如 FCA）、唛头（如 FANATEC）
   - 原产地（默认 China）、海关编码（如 9504 50 0000）、税率（默认 0）
   - 船名/航次、ETD（预计开船）、ETA（预计到港）、运费说明（如 ALU 1264 pcs）
   - 送货单号、签收人、备注
3. 填明细行：客户 PO、Lot、**箱数 / 净重 / 毛重 / CBM**、柜号、封条、HBL
   - 同一成品分多个柜 / 分批 → 点行尾「**拆行**」，把 1264 台拆成 1260 + 4 两行（照模板）
   - ⚠️ **明细行数量合计必须 = 订单数量**，否则系统拒绝出货
4. 点「**出货**」→ 订单变「已出货」，成品库存自动扣减

### 5. 出货后补录（船务信息经常后到）

- 出货单列表点「**编辑单证**」→ 补/改发票号、柜号、HBL、ETD/ETA 等（只改单据，不动库存）
- 点「**添加节点**」→ 记运输节点：备货 / 装柜 / 开船 / 到港 / 清关（各带时间 + 备注）

### 6. 导出三份单证（出货单列表「导出单证」按钮）

| 单证 | 内容 |
|---|---|
| **收款发票 Official Invoice** | 公司抬头、客户、PO、数量/单价/金额、英文大写金额、Due Date（按 NET 60 自动算）、付款记录（财务登记过的收款自动带入）、银行/SWIFT/VAT、贸易条款 |
| **商业发票 Commercial Invoice** | 收货人/VAT/EORI/通知方、明细带 Lot、唛头、船名航次、ETD/ETA、原产地、海关编码、金额大写 |
| **装箱单 Packing List** | 按柜拆行、箱数/毛净重/CBM 自动合计、SAY TOTAL ... CARTONS、每行 HBL/柜号/封条 |

文件名格式：`erp-<发票号>-<单据>-日期-<导出人>.xlsx`

### 7. 订单收尾

客人收货/收款后，订单页把「已出货」推进到「**已完成**」。

### 8. 删除订单（防呆规则）

- 只能删「**没有任何业务痕迹**」的订单：没生成过采购单、没收货/领料/入库、没出货、没收款、没库存流水
- 有痕迹的订单会明确提示，如「订单已有业务记录，不能删除：2 张采购单」
- 弹窗必须**完整输入订单号**才能确认删除

## 四、常见问题

1. **导出的发票抬头/银行是空的？** → 找老板在 基础资料 → 公司资料 填一次。
2. **发票里客户地址/VAT 是空的？** → 找采购在 基础资料 → 客户 补收货地址/VAT#/EORI/通知方。
3. **收款发票里没有付款记录？** → 财务在财务页登记的客户收款会自动带出，提醒财务登记并关联订单。
4. **出货时提示「明细行数量合计与订单不符」？** → 检查拆行后各成品数量合计是否等于订单台数。
5. **页面改了没生效？** → 浏览器 Ctrl+F5 硬刷新。
