# 工程账号操作手册（ERP 基础资料录入）

> 适用角色：**工程**。录入内容：成品、零件（图片/图档）、BOM。
> 系统地址（局域网）：http://192.168.1.114:5173
> 登录账号：**工程**　初始密码：**88888888**（开发阶段统一密码，暂不需要修改）

---

## 一、工程负责什么

| 工程负责 | 工程不管（系统里也看不到/填不了） |
|---|---|
| 成品：新建、图片 | **价格**：由采购填写（零件列表对工程不显示价格列） |
| 零件：料号 / 图片 / 英文品名 / 中文名称 / 重量 / 版本 / 材质 / 尺寸规格 / 表面处理 / 图档 | **供应商**：由采购负责挂到零件上 |
| BOM：成品由哪些零件组成、每件用量 | 订单 / 采购单 / 收货 / 库存 / 出货 / 财务 |

> 工程登录后只能看到「首页」和「基础资料」两个菜单，其他模块与工程无关。

---

## 二、录入顺序（建议）

1. 先建**成品**
2. 再录**零件**（编号照采购单抄，上传图片/图档）
3. 最后配 **BOM**（保存 BOM 后，零件文件会自动归位到对应成品目录）

---

## 三、操作步骤

### 1. 录成品（基础资料 → 成品）

点「新建成品」，填写：

| 字段 | 说明 |
|---|---|
| SKU | 成品编号，唯一不可重复（如 CSS-SQ、P1927-DAPM） |
| 名称 | 成品名称 |
| 单位 | 默认「件」 |
| 图片 | 点上传，选成品照片（可选；显示为同比例缩略图，点击可放大） |

### 2. 录零件（基础资料 → 零件）

点「新建零件」，填写：

| 字段 | 说明 |
|---|---|
| 料号 | **零件固有编号，照采购单抄**（如 P1927-14872），唯一不可重复 |
| 中文名称 | 零件名称（如 变速杆罩） |
| 英文品名 | 英文名称，没有可不填 |
| 重量(g) | 单件重量，按表格原样填（可带 g 或备注文字） |
| 版本 | 图档/零件版本号（如 004、1） |
| 材质 | 材料（如 6063-T6、1.4301 不锈钢） |
| 尺寸规格 | 长宽厚/直径等（如 D15*50） |
| 表面处理 | 阳极/电镀/电泳等 |
| 图片 | 点「上传图片」选零件照片；支持 jpg / png / webp / gif |
| 图档 | 点「上传图档」传图纸/技术文件；支持 pdf / dwg / dxf / step / stp / igs / zip / xlsx，单个文件 ≤ 20MB |

> 零件列表**没有价格、供应商字段**（这两项由采购负责），工程不用管；也没有序号/用量列（这两项在「BOM 维护」页按成品看）。
> 列表自动按「产品族前缀 + 编号大小」排序（如 CSS-001、CSS-012…，P1927-14872、P1927-14873…），同一产品的零件会排在一起。表格上方：「成品」下拉可只看某个成品的零件（默认全部零件）；搜索框支持按**料号/中文名称/英文品名/供应商/表面处理**模糊搜索（回车或点按钮搜索，清空恢复全部，翻页保持筛选与搜索条件）。

### 3. 配 BOM（基础资料 → BOM 维护）

1. 顶部「选择成品」下拉选成品
2. 点「添加零件」——新行出现在**第一行**：最左列是零件图片缩略图，下拉选零件、填用量（每件成品用几个）
3. 连续点「添加零件」可继续加（新行始终在最上面）
4. 加完点「**保存 BOM**」
5. 需要表格版清单时点「**导出表格**」——一键下载 xlsx（工程导出 13 列：序号/料号/图片/Description-EN/英文品名/中文名称/重量/版本/材质/尺寸规格/表面处理/用量/供应商；采购/老板导出多一列「价格」；图片列嵌入零件缩略图、表头样式+冻结首行、每列带排序筛选，文件名 erp-<成品SKU>-BOM-日期.xlsx）

> 注意：没选零件或用量 ≤ 0 的行保存时会**弹提示**（不会静默丢失），补全或删掉该行再保存；同一零件重复添加也会提示合并。

## 四、上传文件的存放规则（自动的，不用手动整理）

上传图片/图档后，系统自动按下面规则放文件，无需工程手工建目录：

- 挂在 1 个成品下的零件：`成品SKU/零件SKU-零件名/零件SKU-零件名.png、零件SKU-零件名-图档.pdf`（文件名带零件名）
- 还没配 BOM 的新零件：先放 `_未分类/零件SKU-零件名/`，**保存 BOM 后自动归位到成品目录**
- 一个零件被多个成品共用：放 `_共用/`
- 成品图片：`成品SKU/成品SKU-成品名.png`

改名零件会同步改文件夹和文件名；删除零件会删掉它的文件。

> 上传图片时表单里要先填好 SKU 和名称（否则会提示）；文件必须真实图片/图档（系统会校验内容，伪造文件会被拒绝）。

---

## 五、如果手里有现成表格（重要）

**不需要一条条手录**：把 Excel 表格全部发给开发人员，由开发人员批量导入。建议表格按下面三张 sheet 整理（列名照抄）：

**sheet「成品」**：成品SKU ｜ 成品名称 ｜ 单位

**sheet「零件」**：料号 ｜ 图片 ｜ 英文品名 ｜ 中文名称 ｜ 重量(g) ｜ 版本 ｜ 材质 ｜ 尺寸规格 ｜ 表面处理 ｜ 用量 ｜ 图档 ｜ 价格 ｜ 供应商（按工程 CSP_V3 清单口径；Description-EN、用在何处、生产工艺、序号、模具、起订量、图号 列不要）

**sheet「BOM」**：成品SKU ｜ 零件SKU ｜ 用量

图片/图档如果也很多：打包发开发人员，文件名按 `零件SKU-零件名-图片.png`、`零件SKU-零件名-图档.pdf` 命名，开发人员批量导入后系统会自动放进对应目录。

## 六、常见问题

- 遇到问题：右下角「意见反馈」提交，开发人员会看到。
- SKU 重复会报错「已存在」：说明这条录过了，直接改原记录即可。
- 忘密码：找开发人员重置。
- 图片/图档传错：编辑该零件重新上传即可覆盖。
- 看不到价格/供应商：正常——这两项归采购，工程界面本来就不显示。
